# MP Report Card Backend

Backend API server for the Canadian MP Report Card application.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create a `.env` in /backend file with:
```
PORT=5001
NODE_ENV=development
```

3. Start the development server:
```bash
npm run dev
```
